# NexSocial - Modern Social Media Dashboard

This is a premium, responsive social media dashboard built with React and Tailwind CSS.

## 🚀 How to Run Locally

Follow these steps exactly to get the project running:

1. **Open your terminal** (Command Prompt, PowerShell, or VS Code Terminal).
2. **Navigate to the project folder**:
   ```bash
   cd "C:\Users\Admin\Desktop\Social Media"
   ```
3. **Install the dependencies**:
   ```bash
   npm install
   ```
4. **Start the development server**:
   ```bash
   npm run dev
   ```
5. **Open your browser** and go to the URL shown in the terminal (usually `http://localhost:5173`).

## 🛠️ Tech Stack
- **React.js** (Vite)
- **Tailwind CSS** (Styling)
- **Framer Motion** (Animations)
- **Lucide React** (Icons)
- **React Router DOM** (Navigation)

## ✨ Features
- Dark/Light Mode
- Interactive Feed (Like/Save/Comment)
- Real-time Chat UI
- Profile, Explore, Notifications & Settings pages
- Responsive Design (Mobile & Desktop)
